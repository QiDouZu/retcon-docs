## ⚠️ 用之前先看这一页

**[声明：拒绝选择性取用（附危险提示）](https://github.com/QiDouZu/retcon-form/blob/main/声明_拒绝选择性取用.md)**

这套东西**可以让人更自信地说错话**——形式完备的判断比随口一句更可信，但它可能只是填得整齐。
**只拿走一角，剩下的就不是辩证法，是更危险的半成品**：只取「欢迎来打」→ 免责套话；只取五栏 → 填空题；只取「推翻条件」→ 更高级的自信；只取「可推翻」→ 每次推翻都无痕。

**能用的最低要求三件**：承认这是假设 · 写出什么情况下它错 · 错了留痕。**缺一件请别用；选择性取用产生的任何问题，作者概不负责。**

**验证方式不是「拿一角试试」**：先**备份**你原来的判断方式，再**整框更替**，用完回头看备份。
验证的产物不是"它好不好用"，是"用了之后你写不写得出来"。

**为什么不能自己解读**：**归因有三层失败——单因、错归、不全；三层都读不出辩证法，第三层最狠：不全读出来的不是"一个原因"，是"一个看起来完整的半成品"。**
带着单因的脑子去拆多因的东西，拆出来的是半成品；带着错归的脑子去拆，半成品挂在了错的地方；带着不全的脑子去拆，半成品会被误认成成品。
